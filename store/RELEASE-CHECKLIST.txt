Signing:
Create a NEW Play Console app for com.tripperdeelabs.motothrash.
This intentionally replaces the old, unsubmitted Dirt Rush package identity.
For a new app, create and securely back up an upload key outside this repository;
use Play App Signing. Do not send private keys/passwords through chat.
Set MOTO_UPLOAD_KEYSTORE, MOTO_UPLOAD_ALIAS and MOTO_UPLOAD_PASSWORD locally,
then run: python3 tools/build_android_release.py --sign
Godot must have its matching templates, JDK 17 and Android SDK configured.
Optional --godot and --templates select local installations.
Unsigned validation build: omit --sign. Never upload the unsigned bundle.
Validate the signed output with bundletool validate and jarsigner -verify;
install APKs generated from that exact bundle before distributing it.
Increase version code for every subsequent Play upload.
